# OmniCore Default Pixel Assets

This folder contains a tiny 16x16 tilesheet for first-hour tutorials and
generated starter projects.

## Files

- `default-tilesheet.svg`: 4 tiles, each 16x16 pixels: player, grass, crate, NPC.
- `default-atlas.json`: frame metadata for the tilesheet.
