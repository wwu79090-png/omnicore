# 3D Runtime Demo

This demo is the official OmniCore production 3D path smoke scene. It uses `Runtime3DScene`, `ThreeRuntimeAdapter`, optional Rapier 3D compat, GLTF/GLB inspection, PBR material metadata, shadow lights, animation preview state, collider debug draw, and `WebGPUPipelineRuntime` resource lifecycle evidence.

Run it from the repository root:

```bash
npx vite --host 127.0.0.1 --port 43174
```

Open `/examples/3d-runtime-demo/index.html`.

The same `scene.omnicore.json` can be opened by the desktop editor with `scene-3d-viewport` real-preview enabled.
