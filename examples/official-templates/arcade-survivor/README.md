# Official OmniCore Arcade Survivor Template

This is a 10 minute complete game starter for first-time OmniCore users. It includes player movement, collectible scoring, enemy pressure, collision checks, restart flow, and tween feedback without adding dependencies beyond OmniCore and Vite.

Run:

```bash
npm install
npm run dev
```

Controls:

- WASD or arrow keys: move
- R: restart after a hit

The template is intentionally small enough to inspect in one file while still showing a complete playable loop.
