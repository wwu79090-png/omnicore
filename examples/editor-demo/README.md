# OmniCore Editor Demo

This demo is a preconfigured scene for users who want to 直接体验编辑流程 before creating a full game.

Open `index.html` in a static server or load `scene.json` in the OmniCore editor.

The scene includes:

- a small Entity / Node hierarchy;
- editable transform fields such as `x`, `y`, `scale`, and `rotation`;
- sample components mounted on entities;
- a Tilemap collision layer flag;
- a preview state for run, pause, and step-frame workflows.

Recommended checks:

1. Select `Player` in the scene tree.
2. Change `x` and `scale` in the inspector.
3. Switch Gizmo modes with `W`, `E`, and `R`.
4. Toggle the collision layer in the Tilemap panel.
5. Run, pause, and step the preview mode.
