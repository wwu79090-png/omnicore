# Physics Debug Draw Demo

This demo exercises the public `@omnicore/physics` package with a stateful arcade world, a dynamic body, a static collider, a sensor trigger, a distance constraint, a raycast probe, and debug draw output.

Run with:

```bash
npm run dev --workspace examples/physics-debug-draw-demo
```

The canvas draws colliders, sensor zones, constraint lines, and raycast hit points while the side panel shows the diagnostics snapshot.
