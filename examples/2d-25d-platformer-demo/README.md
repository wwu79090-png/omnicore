# 2D/2.5D Platformer Demo

This official OmniCore demo is a playable 2D/2.5D platformer template. It demonstrates tilemap editing output, one-way platforms, slope collision, a moving platform, sensor triggers, Light2D-style lighting, Arcade animation state switching, Y-sort preview, debug overlay, hot reload event payloads, camera zones, camera director deadzone follow, parallax layers, shake trauma, combat hitboxes, hitstop, hurt flashes, impact particles, combo windows, encounter director AI, threat budget, spawn waves, projectile director firing, projectile pool telemetry, pierce and bounce tuning, interactable director prompts, switches and doors, chests and checkpoints, NPC dialogue hooks, collectibles, checkpoints, enemy patrols, frame budget telemetry, input buffer, coyote time, variable jump height, and one-way drop-through controller tuning.

Run it with:

```bash
npm install
npm run dev
```

The demo is intentionally compact so it can be used as a starting point for editor playtest flows and exported game templates.
