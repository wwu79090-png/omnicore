# 2D/2.5D Platformer Demo

This official OmniCore demo is a playable 2D/2.5D platformer template. It demonstrates tilemap editing output, one-way platforms, slope collision, a moving platform, sensor triggers, Light2D-style lighting, Arcade animation state switching, Y-sort preview, debug overlay, and hot reload event payloads.

Run it with:

```bash
npm install
npm run dev
```

The demo is intentionally compact so it can be used as a starting point for editor playtest flows and exported game templates.
