# OmniCore Industrial 2.5D Demo

This demo is a small market-facing technical showcase for OmniCore 2.5D production workflows.

- Spine FFD shader descriptors for high quality character deformation.
- Dynamic occlusion through `Dimension3D.PlaneLayer.composeScene2D`.
- 3D city decor batching with `compileStaticModelInstances`.
- Parallax camera and 2D/3D viewport sync.
- HD-2D filter descriptors for normal-lit, stylized 2D presentation.

Run with:

```bash
npm run dev
```
