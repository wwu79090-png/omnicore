# Security Policy

## Supported Versions

OmniCore v1.0.0 receives security fixes on the public `main` branch and release tags. Older experimental tags are best-effort only unless a maintainer explicitly marks them as supported.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| < 1.0.0 | No |

## Reporting a Vulnerability

Please do not open public issues for vulnerabilities that expose users, tokens, build secrets, or package integrity risks.

Report privately through GitHub Security Advisories when available, or contact the maintainer:

- GitHub: `wwu79090-png/omnicore`
- QQ: `3424636983`
- WeChat: `lookkiitylou`

Include affected version, reproduction steps, runtime platform, stack trace, and whether the issue affects browser runtime, npm packaging, CI, or deployment.

## Response Target

- Initial triage: 7 days
- Confirmed high-impact fix target: 14 days
- Disclosure: after a patched release or after the reporter and maintainer agree on timing
