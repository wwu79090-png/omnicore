# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Standards

Participants should keep discussions focused, respectful, and actionable. Technical disagreement is welcome when it includes evidence, reproduction steps, or a clear alternative.

Unacceptable behavior includes harassment, personal attacks, spam, private information disclosure, and repeated off-topic disruption.

## Enforcement

Maintainers may edit, hide, or remove comments and may block users who repeatedly violate this policy. Reports can be sent through GitHub project contact routes or directly to the maintainer:
