# OmniCore 30 秒短视频脚本

目标平台：B 站、抖音、视频号、即刻视频、X/Reddit 附件。

画幅建议：竖屏 1080x1920 或横屏 1920x1080。节奏要快，不讲大而全，只让观众记住“学生 + AI 辅助 + 33KB + 144 FPS + 三行跑起来”。

## 旁白

我用 4 个月做了一个超轻量 Web 游戏引擎 OmniCore。

Lean Core 约 33KB，1000 个 Sprite 演示能跑到 144 FPS。

它支持在线 Playground、轻量编辑器、微信小游戏构建和 590 个测试用例。

这是学生项目，开发中用了 AI 辅助写测试、文档和重复工程活。

如果你做 Web 小游戏，欢迎来 GitHub 试试，顺手点个 Star。

## BGM 建议

- 95-110 BPM。
- 电子、清爽、无歌词。
- 音量低于旁白 12-16 dB。
- 如果没有素材，可以用 `website/promo/30s-demo.html` 的浏览器合成 BGM 做临时版本。
