# OmniCore v0.2.0 Draft Release Notes

## Added

- Automated maintenance system with health checks, deprecated API audit, security check, and local AI code scan template.
- Storage engine version tracking and no-overwrite migration hook.
- GitHub Actions maintenance workflow for scheduled and release-triggered checks.
- Platform guidance for web, WeChat Mini Game, and Douyin Mini Game deployment.

## Fixed

- Maintenance reports now provide rollback-oriented evidence before release.

## Deprecated

- `OmniCore.Backend.use()` is deprecated in favor of `OmniCore.Backend.switch()`.
- `OmniCore.Storage.read()` is deprecated in favor of `OmniCore.Storage.get()`.
- `OmniCore.Storage.write()` is deprecated in favor of `OmniCore.Storage.set()`.

## Migration

- `v1.0.0_to_v2.0.0.js` demonstrates lossless player data migration by preserving `playerData` in `__backup.playerData`.
