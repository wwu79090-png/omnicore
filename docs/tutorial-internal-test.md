# 新手文档内部测试记录

测试目标：让零基础开发者按中文教程完成“创建角色 -> 移动 -> 加载地图”。

## 测试脚本

1. 打开 `docs/getting-started-zero.zh-CN.md`。
2. 按教程创建 basic 项目。
3. 复制“创建角色”代码。
4. 复制“让角色移动”代码。
5. 添加 `assets/maps/first-map.json`。
6. 刷新页面，确认角色出现在出生点，并能用方向键移动。

## 已根据常见问题优化

- 把 `Scene` 解释成房间，把 `Sprite` 解释成角色图片。
- 明确截图参考路径。
- 地图示例使用最小 JSON，避免读者先学习 Tilemap 全格式。
- 把 Loader 错误定位写成资源路径检查步骤。
