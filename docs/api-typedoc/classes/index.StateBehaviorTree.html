    Class StateBehaviorTree

    State-machine behavior tree used by EventSheet.

    It keeps state transitions declarative while using Store as the source of truth. onStateEnter and onStateExit hooks reuse EventSheet-style actions.

    Example

    const tree = new BehaviorTree({ initial: 'idle', states: { idle: { transitions: [] } } }, { store });
    tree.attach();
