    Class TaskManager

    Generator-based coroutine task runner using an independent timer loop.

    Example

    OmniCore.Task.start(function* showThenHide() {
      yield OmniCore.Task.wait(2000);
      button.visible = true;
      yield OmniCore.Task.wait(1000);
      button.visible = false;
    });
