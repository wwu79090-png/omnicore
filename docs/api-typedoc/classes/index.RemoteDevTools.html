    Class RemoteDevTools

    Remote debug snapshot broadcaster.

    The class is intentionally transport-light: production tools may pass a real WebSocket server, while tests can pass any object with clients[].send().

    Example

    const tools = new RemoteDevTools(game, { debug: true, server });
    tools.attach();
