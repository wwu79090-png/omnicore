    Class WebGLContextManager

    WebGL context loss/restoration manager.

    The manager listens to browser webglcontextlost and webglcontextrestored events, prevents the default hard failure path, and calls a canvas fallback hook when the context cannot be restored quickly.

    Example

    const manager = new WebGLContextManager({
      canvas,
      onFallback: () => OmniCore.Backend.switch('canvas')
    });
