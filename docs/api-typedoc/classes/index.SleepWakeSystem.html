    Class SleepWakeSystem

    Distance-based sleep and wake system for NPCs and enemies.

    Entities can opt in with kind: 'npc', kind: 'enemy', tags: ['npc'], or sleepable: true. Sleeping entities skip logic updates until the player is back inside the wake radius.

    Example

    const sleepWake = new SleepWakeSystem({ player, distance: 640 });
    if (sleepWake.shouldUpdate(enemy, scene)) enemy.update(delta);
