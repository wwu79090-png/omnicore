    Class EventBus

    Tiny event emitter used by scenes, UI elements, loader, and debug tooling.

    Example

    const bus = new EventBus();
    const off = bus.on('ready', (payload) => console.log(payload));
    bus.emit('ready', { scene: 'boot' });
    off();
