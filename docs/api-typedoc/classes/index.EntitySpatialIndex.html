    Class EntitySpatialIndex

    Uniform-grid spatial index for 2D entities.

    Entities are assigned to one 32x32 cell by their x and y position. When possible, the index installs lightweight setters so moving an indexed entity updates cell membership immediately.

    Example

    const enemy = OmniCore.Query.add({ x: 64, y: 32, kind: 'enemy' });
    const nearby = OmniCore.Query.inRadius(player.x, player.y, 160, (item) => item.kind === 'enemy');
