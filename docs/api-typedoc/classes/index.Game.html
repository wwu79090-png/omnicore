    Class Game

    Public Game wrapper.

    Keeps CoreGame behavior intact while adding optional headless runtime, automatic platform override, and debug helper attachment from src/index.js.

    Example

    const game = await new Game({ headless: true, autoStart: false }).init();

    Deprecated

    since 0.3.0, removeIn 2.0.0. Use createGame(config) for new projects.
