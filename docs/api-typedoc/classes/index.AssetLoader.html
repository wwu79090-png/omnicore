    Class AssetLoader

    Defensive image asset loader with missing-texture fallback.

    Single image failures are converted into a generated Pixi.Graphics square so bundle loading can continue and scenes can still render a visible placeholder.

    Example

    const loader = new AssetLoader();
    const hero = await loader.loadImage({ key: 'hero', url: '/hero.png' });
    scene.add(new OmniCore.Sprite(hero.texture || hero.displayObject));
