    Class Loop

    Fixed-step requestAnimationFrame loop.

    Locks updates to 60 FPS, reports delta/interpolation, and pauses/resumes on page visibility changes. The internal ticker is intentionally not exposed.

    Example

    const loop = new Loop();
    loop.subscribe((dt, time, alpha) => scene.update(dt, time, alpha));
    loop.start();
