    Class PerformanceMonitor

    Debug-only runtime performance monitor.

    Shows FPS, render time, active GameObject count, and memory usage in the top-right corner when debug: true. It also warns when FPS remains below a threshold for several consecutive frames.

    Example

    const monitor = new PerformanceMonitor({ debug: true });
    monitor.attach();
    monitor.update({ fps: 58, renderMs: 2.4, gameObjects: 12 });
