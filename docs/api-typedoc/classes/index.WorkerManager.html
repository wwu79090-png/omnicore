    Class WorkerManager

    Worker task facade with main-thread fallback.

    Example

    const worker = new WorkerManager();
    worker.register('sum', ({ values }) => values.reduce((a, b) => a + b, 0));
    await worker.run('sum', { values: [1, 2, 3] });
