    Class PixiRenderer

    PixiJS v8 backed 2D renderer with Canvas fallback.

    Pixi lifecycle is sealed behind this wrapper. OmniCore does not expose Pixi's ticker; rendering is driven by OmniCore.Loop.

    Example

    const renderer = new PixiRenderer({ backend: 'pixi', canvas, width: 800, height: 600 });
    await renderer.init();
    renderer.applyBloom(sprite.displayObject);
