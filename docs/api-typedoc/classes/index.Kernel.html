    Class Kernel

    Optional microkernel runtime for addon-based extensions.

    This module is isolated from the legacy OmniCore.Game implementation and is only activated through microkernel.enabled.

    Example

    const kernel = new Kernel();
    kernel.addon('telemetry', { init() {}, destroy() {} });
    kernel.use('telemetry');
