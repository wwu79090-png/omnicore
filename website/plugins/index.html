A* Pathfinding

Tile-based enemy navigation with a small A* style API.

npm install @omnicore/plugin-ai-pathfinding

Open demo

Cloud Save

Local-first save slots with a cloud adapter hook for production.

npm install @omnicore/plugin-save-cloud

Open demo

3D Particles

2.5D burst particles that run without adding rendering dependencies.

npm install @omnicore/plugin-three-d-particles

Open demo

Localization

Runtime locale switching and parameterized strings for UI-heavy games.

npm install @omnicore/plugin-localization

Camera Shake

Reusable screen shake presets for combat, explosions, and impacts.

npm install @omnicore/plugin-camera-shake

WeChat Mini Game Monetization

微信小游戏支付、激励视频广告和 banner 广告的官方轻量接入层。

npm install @omnicore/plugin-wechat-monetization
