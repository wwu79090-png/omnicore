Steam/Itch.io 发布教程

Steam Windows

  1. 运行 npm run build 和桌面打包命令。
  2. 复制 Windows 包到 SteamPipe depot。
  3. 使用 SteamPipe 上传并绑定 Windows 分支。

Steam Linux

  1. 生成 Linux AppImage 或 unpacked 包。
  2. 设置执行权限并上传 Linux depot。
  3. 在 Linux 桌面或 Steam Deck 做启动测试。

Itch.io Windows

  1. 安装 Butler 并登录。
  2. 使用 butler push dist/publish/itch/windows account/game:windows 上传。

Itch.io Linux

  1. 复制 AppImage 到 Linux channel 目录。
  2. 使用 butler push dist/publish/itch/linux account/game:linux 上传。

移动 WebView 壳

运行 npm run build:mobile 生成 iOS Swift 与 Android Kotlin 项目，再把 Web 构建产物放入原生资源目录。
