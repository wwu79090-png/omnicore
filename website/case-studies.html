OmniCore 市场案例与发布证明

这些案例覆盖微信小游戏、Web 模板和桌面编辑器工作流，用来证明 OmniCore 不只停留在 API 演示，而是能支撑可运行模板、性能门禁和发布检查。

代码觉醒者

微信小游戏发布链路验证

2D RPG/解谜混合项目，用于验证 SceneManager、Store、EventSheet、Tilemap Chunk、移动端输入和微信小游戏 4MB 包体门禁。

  • 发布证据：`npm run build:wechat`、`npm run test:wechat`、真机调试手册。
  • 质量门禁：lint、全量测试、benchmark、production-ready。
  • 3D 边界：单 glTF/GLB 只做装饰背景，不进入全 3D 物理。

Starter Platformer

可运行模板

面向新手的 10 分钟 Web 模板，验证角色移动、jump、碰撞、资源加载和 Vite 发布产物。

  • 发布证据：`examples/template-platformer`、`npm run dev`、postbuild 浏览器白屏检查。
  • 质量门禁：模板调试手册、资源 404 检查、全量 Vitest 回归。
  • 商业价值：降低 Phaser/GDevelop 用户迁移到 OmniCore 的入门成本。

Desktop Low-Code Suite

编辑器生产流

Electron 桌面编辑器案例，覆盖工作区扫描、资产预览、Prefab 变体、可视化事件图、UI_Layout 和 config/data.json 数据表编辑。

  • 发布证据：Windows exe、macOS dmg、Linux AppImage 打包目标。
  • 质量门禁：desktop-editor-workflow、lowcode-editor-suite、editor-industrial-authoring。
  • 市场价值：补齐 Unity/Godot/Cocos 对比中最弱的编辑器深度。
