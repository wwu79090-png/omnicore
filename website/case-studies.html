商业案例：代码觉醒者

开发中

项目定位

《代码觉醒者》是一款面向编程学习与剧情冒险结合的 2D 游戏。当前仍处于开发阶段，页面展示的是开发中画面与规划能力。

使用的 OmniCore 能力

  • SceneManager：菜单、关卡、对话场景切换。
  • Store：玩家进度、碎片数量、关卡状态持久化。
  • Input：桌面键盘与移动端 pointer 统一输入。
  • Debug：Live Inspector、性能面板、F1 API 速查。
  • Dimension3D：单 glTF/GLB 赛博朋克城市装饰背景，只做整体旋转。
  • Packaging：离线包与发布流水线支持。

3D 模型仅用于背景氛围，不参与 3D 碰撞、3D 动画或 3D 摄像机控制。
