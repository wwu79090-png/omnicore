# 商业案例与实战验证

## 《代码觉醒者》

![代码觉醒者开发进度截图](./assets/code-awakener-progress.svg)

《代码觉醒者》是一款开发中的 2D RPG/解谜混合项目，用于验证 OmniCore 在真实游戏中的场景切换、RPG 数据配置、事件表状态机、运行时实体编辑和移动端性能表现。

- 开发状态：原型开发中，尚未完成正式发布。
- 引擎特性：Canvas/Pixi 双后端、EventSheet 状态机、Tilemap Chunk、Matter 碰撞掩码、EditorPanel、Worker 数据同步、Dimension3D 单 glTF/GLB 装饰背景。
- 3D 使用边界：赛博朋克城市模型只作为旋转背景层，不参与 3D 碰撞、3D 动画或 3D 摄像机控制。
- 目标：证明 OmniCore 不只是演示框架，而是可以支撑一款真实可玩的 2D 游戏。
