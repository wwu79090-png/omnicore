# OmniCore 公开开发路线图

本文档用于公开说明 OmniCore 未来半年的开发方向。路线图不是强制承诺，具体落地顺序会根据真实项目验证、性能测试和社区反馈调整。

## 已完成

- 33KB Lean Core、WebGPU/Pixi/Canvas 运行时门禁和 benchmark CI。
- Marketplace、插件提交模板、WeChat 发布包和桌面编辑器基础流程。
- 《代码觉醒者》先发案例入口和 `examples/full-game-demo/` 可玩微型游戏。
- 可选匿名遥测本地摘要：默认关闭，只在开发者手动 opt-in 后统计引擎版本、错误类型和 API 使用频率。

## 开发中

- 《代码觉醒者》完整 Demo 场景，把真实问题回流到引擎质量门禁。
- Benchmark 视觉演示展厅，持续展示 1000 Sprite、144 FPS 和 1 Draw Call 目标。
- 编辑器工作流：场景树、属性面板、Gizmo、Tilemap、运行/暂停/逐帧播放。

## 规划中

- 平台适配：Web、Electron、微信小游戏、抖音小游戏的构建模板。
- 插件生态：更多支付、广告、资源管线和平台服务插件。
- 社区案例：公开收集使用 OmniCore 发布的游戏、教程和性能报告。

## 社区反馈

- 功能建议和路线图投票：GitHub Issues。
- 可复现 bug：附最小工程、引擎版本、浏览器/平台和控制台错误。
- 案例提交：提供游戏链接、截图、使用的 OmniCore 模块和上线平台。
