OmniCore 60 秒快速上手视频

这页是官网嵌入位。最终录制建议使用 OBS 或 Screen Studio，按下方四段脚本录制后替换为 CDN 视频源。

当前仓库不提交录屏二进制文件。发布官网时，将 OBS 或 Screen Studio 导出的 60 秒 MP4 挂到 CDN，并在此 video 元素中添加 source。

0-15s

运行 `npx create-omnicore-app my-first-game --template platformer`，展示生成成功。

15-30s

打开项目目录，解释 `src/main.js`、`index.html` 和 `assets/`。

30-45s

运行 `npm install` 和 `npm run dev`，展示首次游戏画面。

45-60s

修改 jump 数值，保存并展示浏览器热更新。
