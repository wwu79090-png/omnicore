OmniCore 迁移入口

这些指南面向已经熟悉 Phaser、Construct/GDevelop 或 Cocos Creator 的开发者。目标不是承诺无损迁移，而是用一个小关卡、一个事件表或一个组件在 30 分钟内验证 OmniCore 是否适合新项目。

从 Phaser 迁移

风险等级: medium

适合 Scene、Sprite、Tween、Input 和 Tilemap 为主的 HTML5 2D 项目。Arcade Physics 细节行为需要重点验证。

打开 Phaser 迁移指南 npm test -- tests/omnicore.test.js

从 Construct / GDevelop 迁移

风险等级: medium

适合把事件表逻辑转成 JSON Event Sheet，并逐步引入 JavaScript、测试和 CI 的团队。

打开 Construct 迁移指南 npm test -- tests/lowcode-editor-suite.test.js

从 Cocos Creator 迁移

风险等级: medium

适合 Web、小游戏和轻量 2D 项目。完整 3D、原生插件和成熟编辑器资产流不建议迁移。

打开 Cocos 迁移指南 npm run build:wechat

30 分钟试用路径

先跑模板，再跑测试和构建，最后迁移一个最小功能。完整清单见 OmniCore 30 分钟试用清单。
