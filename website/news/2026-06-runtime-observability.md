# 2026-06 Runtime Observability

本月重点补齐运行时健康遥测、弱网与低内存模拟、官网案例展示和贡献者预览流程。

- 运行时健康遥测：默认关闭，开发者主动开启后只生成本地聚合摘要。
- 弱网与低内存模拟：用于验证资源加载、降级路径和生产可用性。
- 版本发布说明：同步记录 NPM、离线包、微信小游戏和桌面编辑器状态。
- 社区案例展示：公开收集使用 OmniCore 发布的游戏和模板。

隐私说明：OmniCore 不会默认上传遥测。开发者开启后，默认摘要只包含 FPS、内存估算、渲染后端、WebGL 状态和错误类型计数；接收端由项目方自行部署并负责告知用户。
