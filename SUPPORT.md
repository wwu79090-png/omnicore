# Support

Use GitHub Issues for reproducible bugs, feature requests, compatibility reports, and documentation problems.

## Best Channels

- GitHub Issues: bug reports, reproduction projects, feature requests
- GitHub Discussions or release comments: usage questions and community feedback
- QQ 3424636983: maintainer contact for urgent local coordination
- WeChat lookkiitylou: maintainer contact when GitHub is unavailable

## What To Include

- OmniCore version
- Browser or WebView version
- Device and OS
- Renderer path: Canvas, WebGL, PixiJS, or WebGPU
- Error stack and console warnings
- Minimal reproduction or exported crash bundle from `website/playground/`

## Scope

The project can help with OmniCore APIs, examples, package install issues, browser compatibility, and migration from small Phaser/Pixi-style projects. Full custom game production, paid integration, and private platform certification are outside normal community support.
