# Credits

OmniCore is maintained by the OmniCore Open Engine Maintainers.

## Engine Philosophy

- Logic-driven rendering
- Microkernel runtime
- Minimal native interaction
- Graceful degradation and recovery

## Third-party Runtime Libraries

The legacy full engine can use PixiJS, Three.js, Babylon.js, Nano Stores, and Pixi filters through normal npm dependencies. The lean microkernel runtime in `src/lean/` is dependency-free and activates Addons on demand.

## Default Assets

Default pixel assets and icons are original OmniCore repository assets released under CC0-1.0 for commercial use. See `assets/default/README.md`.
